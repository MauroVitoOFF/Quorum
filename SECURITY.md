# Politica di sicurezza

## Segnalare una vulnerabilità

Non aprire una issue pubblica. Usa la segnalazione privata di GitHub: scheda **Security** della repository, poi **Report a vulnerability**.

Indica la versione di QRM, i passi per riprodurre il problema e l'effetto osservato. Risponderemo il prima possibile; a segnalazione chiusa il problema verrà descritto nel changelog.

## Versioni supportate

Solo l'ultima versione rilasciata riceve correzioni di sicurezza.
